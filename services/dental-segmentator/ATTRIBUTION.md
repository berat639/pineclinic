# DentalSegmentator attribution

This service integrates the DentalSegmentator pretrained nnU-Net model.

- Model: **DentalSegmentator nnU-Net pretrained model for CBCT image segmentation**
- Authors: Gauthier Dot et al.
- Model license: CC BY 4.0
- Model record: https://zenodo.org/records/10829675
- Reference implementation: https://github.com/gaudot/SlicerDentalSegmentator
- Reference implementation license: Apache License 2.0
- Paper: https://doi.org/10.1016/j.jdent.2024.105130

The application-specific HTTP service and dental-arch extraction code in this
directory are original integration code for this project.
